# 🕹️ LED Matrix Tetris

Playable Tetris on the onboard LED matrix of the Arduino UNO Q, controlled with an analog joystick.

Wiring: VRx -> A0, VRy -> A1, SW -> D2, VCC -> 3.3V, GND -> GND.

Controls: left/right = move, up = rotate, down = soft drop, button = hard drop.

Full details: https://github.com/Circuit-Digest/arduino-uno-q-tetris-app
